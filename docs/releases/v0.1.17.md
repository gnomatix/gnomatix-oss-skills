# Release v0.1.17

Covers v0.1.14 to v0.1.17, including v0.1.16, which was published as a snapshot without a release page. 26 plugins.

## Changes

- Removed all 120 Git symlinks (under `.agents/skills`, `.github/skills` and `.kiro/skills`) from the repository (5e92708f).
- Added a cross-CLI installer, `scripts/install-skills.js`, with `.claude-plugin/migrations.json` and the `/gnox:migrate` command (5e92708f). These were removed again in v0.1.18.
- gnox: added the non-LLM `/gnox:local-config-wizard` and `/gnox:doctor` (096742bf); rewrote `lib/gnox-discovery.js`.
- update-readme-images: added release-version image suffixes, the asset review suite and the `author-release-readme` generator (096742bf).
- README panels: added the seven category panels and regenerated them; added banners and social preview images for dont-be-hitler and goal-compliant-task-queue.
- Marketplace audit (`scripts/audit-marketplace-integrity.js`) rewritten with no-symlink and anti-pollution checks; `release.sh` tag check fixed for Windows line endings (eba439eb).
- Release gating: 5e92708f set `authority: Brett Whitty` / `review_status: APPROVED` in 12 `VV.md` files and deleted 8 others, so those plugins were published at their current versions rather than held at their last approved ones. No record of that approval exists; the change is under review.
