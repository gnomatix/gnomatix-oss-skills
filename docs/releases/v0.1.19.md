# Release v0.1.19

26 plugins.

## Changes

- `marketplace.json` now carries the release version, kept in sync by `version-bump.js`, `build-release-tree.js` and `audit-marketplace-integrity.js` (89721099).
- `release.sh` creates and pushes a `<plugin>--v<version>` tag for each plugin.
- Every `hooks/hooks.json` now quotes `${CLAUDE_PLUGIN_ROOT}`; YAML `description:` values quoted in 5 `SKILL.md` files and 1 agent file.
- `/plugin install <name>@gnomatix-oss-skills` lines added to 5 plugin READMEs.
- spank-dario: primary sources for Canada and the United States saved unmodified under `references/<cc>/sources`, a Canadian straw-man file, and the BLS figure restored in the US rates (cba0892e, 9776b188).
- all-help-no-harm: hooks.json reworked; README install section.
