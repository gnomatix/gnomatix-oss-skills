# Release v0.1.19 — "strict claude plugin validate, per-plugin release tags, & marketplace version sync"

![Release v0.1.19 — strict claude plugin validate, per-plugin release tags, & marketplace version sync](../../assets/images/releases/release-v0.1.19-banner.jpg)

Marketplace release **`v0.1.19`** (since `v0.1.18`) publishes **26 standalone/complementary plugins** across Claude Code, OpenAI Codex, Antigravity CLI (`agy`), GitHub Copilot, VS Code, Cursor, OpenCode, and Kiro with zero Git symlinks (`120000`).

## Headline Changes

- **Top-Level `.claude-plugin/marketplace.json#version` Sync**: Synchronized top-level `"version"` in `.claude-plugin/marketplace.json` with `VERSION` and `.VERSIONS.json#_marketplace.version` across `scripts/version-bump.js`, `scripts/build-release-tree.js`, and `scripts/audit-marketplace-integrity.js`.
- **Per-Plugin `<plugin>--v<version>` Release Tags**: Updated `scripts/release.sh` to create and push Claude Code's native `<plugin>--v<version>` tags alongside repo-level `v<VERSION>` tags for every published plugin.
- **Zero-Warning `claude plugin validate --strict .`**: Quoted `${CLAUDE_PLUGIN_ROOT}` across all `hooks/hooks.json` files, quoted YAML `description:` scalars containing colons/embedded quotes across `SKILL.md` and `agents/*.md`, and added `/plugin install <name> --marketplace gnomatix/gnomatix-oss-skills` snippets to all plugin READMEs.
- **Native Claude Code Marketplace Renames & `mise` Skill Sync**: Configured top-level `renames` and `forceRemoveDeletedPlugins` in `.claude-plugin/marketplace.json` alongside declarative `mise.toml` (`mise skills sync --prune`, `mise run doctor`).
