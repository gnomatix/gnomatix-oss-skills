# Release v0.1.18

26 plugins.

## Changes

- Removed the v0.1.17 cross-CLI installer (`scripts/install-skills.js`), `.claude-plugin/migrations.json`, the `/gnox:migrate` command and their tests (3ebed126).
- `marketplace.json`: added top-level `renames` (3 entries) and `forceRemoveDeletedPlugins: true`; added `mise.toml` (3ebed126).
- Plugin READMEs: the install line for agents other than Claude Code now points at the Agent Skills folder instead of the removed installer.
- gnox doctor no longer runs the cross-CLI install checks; the marketplace audit and its tests were reworked.
