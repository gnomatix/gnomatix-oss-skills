# Release v0.1.21: Primary sources, kept as published

Every law and vendor-terms quotation in spank-dario now traces to a primary source saved unmodified in the repository and dated; citation-farm-audit is tested live against OpenAlex; release notes are written from the actual history.

Marketplace release **`v0.1.21`** (since `v0.1.20`) publishes 26 plugins.

## Changes

- spank-dario: primary sources for Australia, Canada, Ireland, Japan, the UK, the US, the EU and Berne saved byte for byte under references/<country>/sources, every entry re-checked and dated
- spank-dario: Moffatt v. Air Canada (2024 BCCRT 149) saved as CanLII's PDF; all six paragraph entries checked against it
- spank-dario: two new tests: every reference file's verification claim matches its entries, and primary sources are stored byte for byte
- citation-farm-audit: its test now runs the OpenAlex profile live, against a real author record
- release notes for v0.1.17 to v0.1.20 rewritten from the git history; the generator now writes only real changes
- Fix (marketplace): the claude.ai hosted sync report is cleared (2 skipped plugins, 35 warnings): top-level bin/ moved to scripts/ in skill-vv, goal-compliant-task-queue and compelling-use-case, plugin and SKILL.md descriptions brought within the hosted limits, and a new audit rule, hosted-sync-limits, refuses each cause
- Feature (update-readme-images): layered config, readme-images-default.json with an empty readme-images-user.json that overrides or extends it; a release banner prompt file written per release; release notes list EPIC, FEATURE and BUGFIX commits and collapse the rest to one count per scope
- Fix (update-readme-images): the release banner prompt stays inside the project-visuals directory, and only style documents under the repository, the plugin or project-visuals are inlined
- Feature (gnox): the session hook and the gnox skill now carry a mandatory-use rule: every installed GNOX plugin or skill that applies is invoked before any response or action
