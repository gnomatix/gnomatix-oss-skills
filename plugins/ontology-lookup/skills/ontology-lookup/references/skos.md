# SKOS — `skos`

**For:** the vocabulary of vocabularies: `prefLabel`, `altLabel`, `broader`, `narrower`, `exactMatch`, `Concept`, `ConceptScheme`. Tag with it when a passage is *about* labelling or mapping terms (for example "the preferred label of X is Y").

**Prefix:** `skos` (Bioregistry `skos`; URI `http://www.w3.org/2004/02/skos/core#$1`). Example: «preferred label» [skos:prefLabel].

**Licence:** a W3C Recommendation, under the W3C document licence (https://www.w3.org/Consortium/Legal/copyright-documents, linked from the specification's copyright notice); Bioregistry records it as `W3C-2023`. Checked: https://www.w3.org/TR/skos-reference/

**Query:**
- OLS4 hosts it as ontology `skos`: `https://www.ebi.ac.uk/ols4/api/search?q=<term>&ontology=skos` (see [bioregistry-and-ols.md](bioregistry-and-ols.md)).
- Download: RDF/XML at `https://www.w3.org/2004/02/skos/core.rdf`.

**In lookup.mjs:** in the default search set, through OLS4.

**Pages checked (2026-11-02):** https://www.w3.org/TR/skos-reference/, https://www.w3.org/2004/02/skos/core.rdf, https://bioregistry.io/api/registry/skos
