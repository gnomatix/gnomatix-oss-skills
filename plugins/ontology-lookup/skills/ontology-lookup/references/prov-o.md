# PROV-O — `prov`

**For:** provenance: who or what made something, from what, by which activity. `Activity`, `Entity`, `Agent`, `wasGeneratedBy`, `wasDerivedFrom`, `wasAttributedTo`. Use it for the relation; the agents and things themselves get their own CURIEs.

**Prefix:** `prov` (Bioregistry `prov`; URI `http://www.w3.org/ns/prov#$1`). Example: «Activity» [prov:Activity].

**Licence:** a W3C Recommendation; its copyright notice links the W3C document licence, https://www.w3.org/Consortium/Legal/copyright-documents. Bioregistry records `W3C-20150513`. Checked: https://www.w3.org/TR/prov-o/

**Query:**
- OLS4 hosts it as `prov`.
- Download: Turtle at `https://www.w3.org/ns/prov-o`.

**In lookup.mjs:** in the default search set, through OLS4.
