# ISO 639-3 — `iso.639-3`

**For:** languages, by three-letter code (eng, deu, ang, enm, lat). Used by the word-lineage mode.

**Prefix:** `iso.639-3` (Bioregistry; URI `https://iso639-3.sil.org/code/$1`). Note the dot: `iso639-3` is not the registered prefix. Bioregistry's lookup accepts `iso639-3` and answers with the `iso.639-3` record, and `lookup.mjs --resolve iso639-3:eng` rewrites it to `iso.639-3:eng` with a note. Example: «English» [iso.639-3:eng].

**Licence (terms of use, not an open licence):** SIL, the registration authority, lets the code set be "downloaded and incorporated into software products, web-based systems, digital devices, etc., either commercial or non-commercial, provided that: attribution is given to iso639-3.sil.org as the source of the codes; the identifiers of the code set are not modified or extended [...]; the product, system, or device does not provide a means to redistribute the code set." Checked: https://iso639-3.sil.org/code_tables/download_tables

Consequence for this skill: it does not ship the code table and does not download it in bulk. It uses single codes, reads names through Wikidata (property P220, "ISO 639-3 code"), and points to `iso639-3.sil.org` as the source.

**Query:**
- Per code: `https://iso639-3.sil.org/code/<code>` (HTML).
- Through Wikidata: items with `wdt:P220 "<code>"` on `https://query.wikidata.org/sparql`.
- Download (for your own use under the terms above): https://iso639-3.sil.org/code_tables/download_tables

**In lookup.mjs:** `--ontology iso.639-3` finds languages by name through Wikidata; `--resolve iso.639-3:<code>` gives the URL and the Wikidata name; `--lineage` attaches the code to each language in the chain.

**Pages checked (2026-11-02):** the URLs above, https://iso639-3.sil.org/code/eng, https://www.wikidata.org/wiki/Special:EntityData/P220.json, https://bioregistry.io/api/registry/iso.639-3
