# BFO (Basic Formal Ontology) — `BFO`

**For:** the upper-level categories the OBO ontologies are built on: `continuant`, `occurrent`, `process`, `role`, `disposition`. Tag with BFO only when the passage is about the category itself; a mitochondrion is tagged with GO, not with BFO's `independent continuant`.

**Prefix:** `BFO` (Bioregistry `bfo`, preferred prefix `BFO`; pattern `^\d{7}$`; URI `http://purl.obolibrary.org/obo/BFO_$1`). Example: «continuant» [BFO:0000002].

**Licence:** CC BY 4.0 (OBO Foundry registry; the BFO repository README states "Content license: Creative Commons 4.0 BY", code under the New BSD License). Checked: https://obofoundry.org/registry/ontologies.jsonld, https://github.com/BFO-ontology/BFO

**Query:**
- OLS4 hosts it as `bfo`.
- Download: `http://purl.obolibrary.org/obo/bfo.owl` (or `bfo.obo`).

**In lookup.mjs:** in the default search set, through OLS4.
