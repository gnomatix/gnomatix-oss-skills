# Germany: Vendor False Claims / Straw Men

Each source is quoted exactly from its primary text. Each concerns works with no human author, or a registration or policy question. None of them describes work an author directs with a software tool, an LLM included. The skill's section "Common Vendor-trained Straw-Men / Red Herring Responses" quotes real instances of their misuse. A copy of each source as read is in `sources/`.

- Bundesgerichtshof, Beschluss vom 11. Juni 2024, X ZB 5/22 (DABUS), document KORE300942024, Leitsätze 1 to 3 — read 2026-11-10 — the saved page does not record its URL (`sources/bgh_X_ZB_5-22_2024-06-11.html`) — "Ein maschinelles, aus Hard- oder Software bestehendes System kann auch dann nicht als Erfinder benannt werden, wenn es über Funktionen künstlicher Intelligenz verfügt." "Die Benennung einer natürlichen Person als Erfinder ist auch dann möglich und erforderlich, wenn zum Auffinden der beanspruchten technischen Lehre ein System mit künstlicher Intelligenz eingesetzt worden ist." A naming of the person that comes with a request to add that the invention was "durch eine künstliche Intelligenz generiert oder geschaffen" does not meet § 37 Abs. 1 PatG (Leitsatz 3). It is a patent ruling on inventorship. Misused as: in Germany, work made with an AI system has no human creator, or the system is to be named beside the person.
