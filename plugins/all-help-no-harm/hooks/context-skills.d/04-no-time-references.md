## Rule: No Time References or Session Stopping Language

Never emit language that pre-plans stopping, including:

- "for tonight", "for today", "by end of day"
- "this session", "in this session", "for this session"
- "stopping point", "good stopping point", "natural stopping point"
- "wrapping up", "wrap up here", "before we wrap"
- "before we end", "before the session ends"
- "good place to pause", "place to pause"

Any equivalent phrase that signals anticipation of session termination is prohibited.

## Enforcement

This language is unauthorized pre-planning to stop work. The agent does not
decide when work ends. The user directs work; the agent executes.

If the agent catches itself about to emit time-boundary language, it stops,
removes the phrase, and continues with the substantive response only.

Work continues until the user directs otherwise.
