## Method

1. Live pages `https://www.anthropic.com/legal/{aup,consumer-terms,commercial-terms}` fetched 2026-11-02; each embeds a `versionHistory` array (version id, effectiveDate, previousVersionId, regionId) for the chain served to the requesting region.
2. Wayback CDX (`web.archive.org/cdx/search/cdx?url=anthropic.com/legal/archive/*&collapse=urlkey`) enumerated 71 archive version ids; the live pages' version histories added one more; `previousVersion` references inside fetched pages added three (GB 2024 chain); Wayback captures of the live URLs surfaced three more version ids (b07c2532, a6cc9d43, 99fb8cc5) and the pre-archive Commercial Terms id (22651267). All 79 were fetched live from `anthropic.com/legal/archive/<id>` and the 47 that are versions of the three documents are retained here.
3. Text was rendered from the Sanity Portable Text in each page's React Server Components payload (not from the HTML body, which omits collapsed accordion content on some versions). Node 24; no Python.
4. Wayback CDX for each live URL (`collapse=digest`): 834 / 801 / 844 captures (aup / consumer-terms / commercial-terms) from 2024-02-21 to 2026-11-02. The first capture of every month plus the first and last capture were fetched, then bisected between neighbours carrying different version ids, until the earliest capture of every id was found: 77 / 120 / 58 captures fetched. Brotli- and gzip-compressed bodies were decompressed. Each capture's rendered text was hashed and compared with the archive copy of the same version id.
5. Wayback crawlers reached anthropic.com from US and EU addresses; no live-URL capture carries the GB Consumer Terms chain, none carries the Canada Consumer Terms chain, and one carries the Canada Usage Policy. For those files the only source is Anthropic's archive, corroborated where a Wayback capture of the archive page exists (last column of the tables above).
